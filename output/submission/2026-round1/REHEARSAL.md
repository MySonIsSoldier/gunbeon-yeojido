# 핵심 기능 5개 · 제출 전 시연 순서

**팀 내부용 약 7분 시연안**이다. 대회가 정한 발표·영상 길이가 아니다. 1차는 기능심사이며 확인한 공식 안내에서 별도 시연 영상 필수 규격은 찾지 못했다. 기능설명서와 실제 서비스가 같은 동작을 설명하도록 준비한다.

접속: https://gunbeon.gangwon.kr/login · 사용법: https://gunbeon.gangwon.kr/guide

이미 준비된 주최 측 지정 일반 심사 계정을 사용한다. 계정 정보를 공개 영상·이미지에 노출하지 않는다. 기존 예시를 보존하고 변경 시 새 사본에서 진행한다. 초대는 72시간·공개 한 수는 30일 유효하므로 제출 직전에 만든다. 현재 출타는 끝내거나 중단해 다음 심사자가 진행 중 상태를 오해하지 않게 한다.

| 순서 | 보여줄 동작 | 설명할 핵심 |
|---|---|---|
| 0:00–0:40 | 로그인 → 홈의 예정 여행·그룹 | “장병과 가족·연인·친구가 함께 일정을 만들고, 장병의 복귀 기준은 개인 사본에서 다룹니다.” 예시는 실제 이용 기록이 아님. |
| 0:40–2:00 | 둘러보기 → 코스 선택 또는 빈 코스 → 관광정보 검색 → 장소 상세/무장애 확인 → 일정 편집·저장 | “한국관광공사 데이터가 장소 선택과 실제 일정 작성으로 연결됩니다.” 조회 성공 시 출처·수신 시각을 보여준다. 실패는 숨기지 않고 기본자료와 구분. |
| 2:00–3:00 | 그룹 여행 열기 → 초대 → 동행자 별도 브라우저 참여 → 개인 여행 사본 만들기 | “함께 바꾸는 공동 원본과 나의 복귀 기준은 분리합니다.” 원본 수정이 개인 사본에 자동 병합된다고 설명하지 않기. |
| 3:00–4:15 | 개인 일정 편집 → 동행 조건 → 여유 조정 → 한 장소 생략/체류시간 감소 → 전후 비교 → 저장 | 가장 중요한 장면. “한 곳을 덜 들르면 추정 복귀 여유가 어떻게 바뀌는지 보고 선택합니다.” 실제 교통과 부대 규정을 보장하는 수치가 아님. |
| 4:15–5:30 | 현재 출타 → 오늘의 기준 확인 → 출발 → 완료 확인 → 방문 장소 선택 → 여행 카드 → 기록 수정·계획 복원 | 계획 시각과 현재 시각의 역할을 구분. GPS 인증이 아니라 직접 확인한 방문 기록. 정확한 개인 시각·직접 입력 장소는 공개 카드에서 제외. |
| 5:30–7:00 | 내 여행의 한 수 부탁하기 → 공개 범위 확인 → 다른 브라우저에서 장소 추가/교체 제안 → 작성자가 검토·실제 저장 → 반영 표시 | “외부의 한 수를 댓글에 두지 않고 실제 여행 변경으로 이어갑니다.” 이용자 증가·관광소비 효과를 검증했다고 설명하지 않기. |

## 종료 후 확인

- 새로 만든 임시 그룹·공개 링크만 종료/정리한다. 다른 사용자의 여행이나 지정 심사 예시를 삭제·초기화하지 않는다.
- 계획 재열기·저장 조건 유지, 출타 종료, 공개 범위, API 출처를 확인한다.
- 성공/실패, 정확한 배포 버전, 기기/브라우저, 시각을 기록한다.
- 캡처는 로딩 종료·장소명 표시·사진 로드 이후 촬영한다. 사진이 원래 없는 경우 정상 플레이스홀더와 로딩 전 오류를 구분한다.

## 예상 질문과 근거 있는 답변

**일반 여행 앱과 무엇이 다른가요?**

공동으로 준비하는 관광 일정과 개인 복귀 기준을 연결하되 구분합니다. 장소를 하나 줄이거나 머무는 시간을 바꿀 때 시간·도보의 변화를 비교하고, 실제 출타와 하루 기록으로 이어집니다.

**한국관광공사 데이터가 꼭 필요한가요?**

국문 관광정보의 지역코드·장소·좌표·상세·사진이 검색과 장소 선택, 일정 표시와 이동 추정의 근거입니다. 무장애 정보는 부모 동행 등의 편의시설 확인에 연결됩니다. 9/16 운영 실호출을 기록했습니다.

**복귀 가능한 시간을 보장하나요?**

아닙니다. 사용자 일정과 거리 기반 이동 추정에 대기·날씨·동행 여유를 더한 참고값입니다. 실제 교통·방문 조건·소속 부대 규정은 직접 확인해야 합니다.

**기록이 자동 인증되나요?**

아닙니다. 사용자가 실제 방문한 장소를 선택해 완료하는 여행 기록입니다. 군번·휴가증·군 신분증·근무표를 수집하지 않고 GPS 방문 인증으로 표현하지 않습니다.

**향후 무엇을 검증하나요?**

계획·초대의 완료율, 외부 제안 반영률, 다음 출타의 재사용률을 실제 장병·동행자와 확인합니다. 먼저 강원 접경 5군의 정보 갱신과 운영 완성도를 높입니다.
