## 접수 순서

1. [참가자 공지](https://lowly-polyanthus-1fb.notion.site/2026-36b5dce406e380e0a3d1f80525667a11)를 마지막으로 확인한다.
2. [한국관광콘텐츠랩](https://api.visitkorea.or.kr)의 기존 신청 계정에서 이메일을 인증하고 최종 팀원을 확인한다.
3. 서비스 주소 **https://gunbeon.gangwon.kr**, 웹 유형, 강원특별자치도 지역특화, 실제 사용 API **국문 관광정보·무장애 여행 정보 2종**을 입력한다.
4. API 신청자의 인코딩/디코딩 키와 지정 일반 심사 계정을 **비공개 지정란에만** 입력한다. 공개 자료에 키·비밀번호를 넣지 않는다.
5. PDF를 첨부하고 13쪽 미리보기 및 파일명을 확인한 뒤 최종 제출한다. 접수 완료 증빙을 별도로 보관한다. 9/20 완료를 권장한다.

화면의 여행·그룹·방문 기록은 기능 설명용 합성 예시다. 실제 이용자 성과·GPS 방문 인증이 아니다. 이동과 복귀 여유는 거리 기반 참고값이다. 스크린샷은 운영 서비스 실동작이며 로딩 중 화면과 API 모의 성공은 제출에 쓰지 않았다. 촬영용 임시 공유 링크는 정리했으므로 시연 시 새 링크를 만든다.

최종 PDF에는 한글 폰트를 포함했다. PPTX는 공식 양식의 맑은 고딕 지정을 유지하므로 다른 PC에서 편집·재내보내기할 때 글꼴과 줄바꿈을 다시 확인한다. [원본 제작 안내](https://github.com/MySonIsSoldier/gunbeon-yeojido/tree/master/scripts/submission).
