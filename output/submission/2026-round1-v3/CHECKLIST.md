## 사용자가 접수 전에 확인할 것

1. **최종 팀원:** 예선 이후 변경 여부와 대표 포함 최대 5명 조건을 확인한다. 팀명·대표는 변경할 수 없고 팀원은 콘텐츠랩 가입 후 등록한다.
2. **신청 계정·메일:** 예선에 사용한 한국관광콘텐츠랩 계정으로 공모전 접수확인을 열고 등록 이메일 인증을 완료한다.
3. **인증키:** 실제 신청자의 국문·무장애 활용 승인과 현재 키를 확인한다. 마이페이지 첫 화면의 개인 API 인증키에서 Encoding/Decoding을 각각 복사해 지정 비공개 입력란에 붙여넣는다. 두 값이 같으면 그대로 입력한다. 공개 PDF·이미지·GitHub에는 넣지 않는다.
4. **접수 입력:** [접수 입력 최종안](https://github.com/MySonIsSoldier/gunbeon-yeojido/blob/master/docs/submission/2026-round1/portal-copy.md)을 사용해 웹 유형·새 URL·서비스명·지역·사용 API가 일치하는지 확인한다. 운영계정 신청 여부는 실제 상태대로 선택한다(선택 사항).
5. **첨부 미리보기:** 최종 v3.2 PDF 18쪽·10MB 이하인지 확인하고 업로드 후 모든 페이지를 확인한다. 대표 1장·상세 3장(일정 보기·복귀 여유 비교·공개 장소 제안)이 v3와 같은 선택인지 대조한다. 영상은 확인한 안내상 필수 아님.
6. **최종제출:** 임시저장에 그치지 않고 3단계 자료 제출 완료 화면·안내 이메일·접수확인 내역을 확인한다. 키·개인정보를 제외한 접수 증빙을 보관한다.
