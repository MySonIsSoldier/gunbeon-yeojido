## 서비스 인증키

**현재 구성: 같은 신청자의 공통 일반 인증키 1쌍**을 입력하고, 아래 실제 활용 API 2종을 모두 선택한다. 로컬 설정에서 국문·무장애가 같은 공통 키를 사용함을 값 공개 없이 확인했다. 로컬 환경 파일과 운영 Secret은 별개이며 제출할 값은 실제 사용 신청자의 공공데이터포털에서 확인한다.

1. 공공데이터포털 로그인 → **마이페이지 첫 화면 → 개인 API 인증키**로 이동한다.
2. **Encoding** 복사 버튼의 값을 접수 ‘인코딩’란에 입력한다.
3. **Decoding** 복사 버튼의 값을 접수 ‘디코딩’란에 입력한다.
4. 두 복사 결과가 같으면 양쪽에 그대로 같은 값을 입력한다. 임의로 인코딩하거나 변형하지 않는다.
5. 신청자가 여러 명인 키를 실제 사용했다면 신청자별 키 쌍을 추가한다. 접수 범위는 최소 1쌍·최대 3쌍이다.

**‘인증키 발급현황’에는 인코딩 키만 표시될 수 있으므로 위의 개인 API 인증키 화면을 사용한다.** 실제 키는 비공개 접수란에만 입력하며 PDF·이미지·GitHub에는 포함하지 않는다. 근거: [공식 인증키 가이드](https://drive.google.com/file/d/1iAy4zLbWT4gWbc7PkW2mujdQBFD-2-BC/view), 이번 사용자 제공 접수 화면의 동일 키 안내.

운영계정 신청은 **선택 사항**이다. 해당 입력란은 실제 신청 상태대로 선택한다. 이번 작업에서 새 신청을 하지 않았으며 신청·승인 여부를 추정하지 않는다.

## 활용 OpenAPI 서비스 — 아래 두 항목만 선택

- **한국관광공사_무장애 여행 정보**

| 서비스 | 현재 활용 |
|---|---|
| 국문 관광정보 서비스(KorService2) | 관광지·음식점·숙박·문화시설·행사 목록과 검색, 공통·소개 상세, 응답의 대표 사진·주소·좌표를 장소 선택·일정·지도·공개 제안 검증에 활용 |
| 무장애 여행 정보(KorWithService2) | 목록·무장애 상세에서 제공되는 주차·접근로·휠체어·화장실 등 편의 정보를 장소 상세와 동행 조건 확인에 활용 |

사진을 사용하더라도 국문 관광정보 응답의 사진이므로 **‘관광사진 정보’ API는 체크하지 않는다.** 집중률·중심 관광지·연관 관광지 API는 시험 호출 이력만 있고 서비스에 통합하지 않아 선택하지 않는다. 기상청·Kakao·통일부·보훈 자료는 한국관광공사 선택 목록에 포함하지 않는다.

9/17 운영에서 국문 철원 5유형 **113건**, 고석정 꽃밭의 국문·무장애 상세와 기상청 8시간 예보의 실제 성공을 확인했다. [실호출·계정 검증](https://github.com/MySonIsSoldier/gunbeon-yeojido/blob/master/reports/qa/submission-final-2026-09-17/live-api.json).
