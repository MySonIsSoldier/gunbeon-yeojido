# 기능설명서 문서 글꼴

Pretendard 1.3.9의 공식 OTF 원본 Regular, SemiBold, Bold다. 사용자 요청에 따라 공모전 기능설명서 본문을 이 글꼴 계열로 편집한다. 공식 양식의 래스터 대회 표지·섹션 제목은 그대로 유지한다.

- 원본: https://github.com/orioncactus/pretendard/releases/tag/v1.3.9
- 내려받은 배포 파일: https://github.com/orioncactus/pretendard/releases/download/v1.3.9/Pretendard-1.3.9.zip
- 원본 ZIP의 `public/static/`에서 추출했다. 글리프·이름·메타데이터를 수정하지 않았다.
- 저작자: Kil Hyung-jin. SIL Open Font License 1.1, 함께 제공한 `OFL.txt` 유지.
- 수정 가능한 PPTX를 다른 PC에서 열 때 세 OTF를 설치한다. 제출 PDF는 실제 글꼴을 포함하므로 별도 설치가 필요 없다.
- Mac 제작 PC에는 사용자 `~/Library/Fonts/`에 동일 원본을 추가했다. 기존 파일을 덮어쓰지 않았으며 시스템/런타임의 폰트 설정은 변경하지 않았다. LibreOffice PDF 변환은 빌드 폴더의 전용 fontconfig를 사용한다.
