# 9/21 민준·openapi 로그인별 체험 분리

사용자 요청: 민준 아래 작은 openapi 자동 입력 버튼, 로그인마다 초기 예시, 같은 기기의 로그인 상태에서는 편집 유지, 다른 이용자와 격리, 명확한 주의사항.

## 제품 동작

- 로그인 화면의 민준 버튼(16px/52px) 아래 openapi 보조 버튼(14px/44px)을 배치했다. ID/공개 테스트 비밀번호만 채우고 실제 로그인은 사용자가 누른다. 두 버튼 옆에 임시 유지·재로그인 초기화·다른 테스터와 격리 안내가 있다.
- 두 계정 모두 비밀번호를 기존 scrypt 인증/호출 제한으로 검증한 뒤 별도 account/profile/travel/groups를 생성한다. 원본 계정에 세션을 새로 발급하지 않는다.
- 민준: 준비 계획4·완료 기록1·그룹3. openapi: 준비 계획3(빈 일정 포함)·완료 기록1·그룹2. 예시 날짜는 새 로그인 기준으로 정하며 실제 인물이 아니다.
- 현재 HttpOnly 세션이 유지되면 새로고침·탭 이동·같은 브라우저 재방문 시 수정한 여행·그룹을 이어 본다. 로그아웃은 해당 세션을 폐기하고 다음 로그인은 원본 예시에서 새로 시작한다. 다른 기기 로그인이 기존 기기의 세션을 초기화하지 않는다.
- 서버에 현재 체험 상태를 임시 보존하므로 ‘전혀 저장하지 않음’이라고 설명하지 않는다. 로그인 유효기간은 기존 14일이며, 생성14일 경과+유효세션 없음인 체험만 제한적으로 청소한다. 공개 제안 링크는 사용자가 명시적으로 발행한 범위를 기존 규칙대로 공개한다.
- 실제 지인 초대/참여·개인 OAuth 연결·기기 여행 가져오기는 두 테스트 계정에서 제한하고 개인 계정으로 안내한다. 개인 일반/소셜 계정의 지속 저장과 그룹 권한은 유지한다.

## 기존 openapi 자료와 세션 전환

추가 migration0006은 기존 openapi의 비밀번호/개인자료/그룹을 삭제하거나 초기화하지 않고 인증 원본 표시만 한다. 새 설치에는 동일 공개 로그인 템플릿을 생성한다. 기존 migration·snapshot은 다시 쓰지 않았다.

이전 공유 심사 계정으로 이미 로그인한 세션은 첫 인증 조회에서 기존 저장 여행과 소유 그룹의 독립 사본을 받는다. 같은 쿠키를 유지하며 조건부 세션 갱신으로 동시 요청도 하나의 사본으로 수렴한다. 이전 화면의 account ID로 저장하려 하면 기존 충돌 보호가 재로딩/백업을 안내한다. 새 로그인은 이전 이용자의 수정본을 읽지 않고 코드의 초기 예시를 이용한다.

이번 사용자 지시는 과거 ‘지정 심사 계정은 지속 저장하는 별도 일반 계정’ 계약을 바꾼다. 이전 원본은 보존하며 운영 전체 초기화/개인 계정 변경은 하지 않는다.

## 검사

- typecheck·121개 단위 통과. public judge seed의 독립성·개인 데이터 whitelist·그룹 DTO 확인.
- 실제 로컬 D1: 두 종류 계정의 동시 로그인, 개인 여행 추가/수정, 그룹 생성/일정 수정, 동일 쿠키 복원, 다른 사용자 조회/저장 거부, 로그아웃 세션 폐기, 초기화 재로그인. 신규 `test:tester-isolation`.
- 로컬 합성 레거시 계정: 저장 자료/그룹 유지, 3개 동시 요청의 한 사본 수렴, 별도 세션 격리, 이전 화면 저장 거부.
- 격리 SQLite fixture: migration의 기존 비밀번호/여행 revision/그룹/세션 보존 및 새 DB 템플릿 생성.
- 기존 민준 API와 일반 계정 API 회귀 통과: 게스트 권한 보존, 개인 계정 다중 기기 복원/충돌, 정상 로그인13회, 인증 실패 제한. 실제 Google/Naver 동의는 이번 검사에서 실행하지 않았다.
- Chrome/Chromium 320·430·1440px 총6개: 버튼 자동입력/안내, 실제 빈 여행 저장→새로고침 유지→로그아웃→재로그인 초기화, 자동20초안내. 페이지 오류·가로 넘침 없음. 물리 기기/Edge 미검사.
- [결과·화면](qa/isolated-testers/). `test:tester-isolation`과 `test:tester-isolation-ui`를 CI에 추가했다. 과거 공유계정 hash 비교 검사는 새 체험 격리 검사로 교체했다.
