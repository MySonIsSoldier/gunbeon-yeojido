# 심사 체험과 이번 휴가 한 장 — 2026-09-17

## 목적과 실제 동작

심사위원이 회원가입 없이 장소 탐색→개인 일정→동행 그룹→공개 제안→출타·기록을 직접 이용하도록 한다. 가상 인물 민준(24세 장병)의 여행 계획4개·그룹3개·지난 기록1개를 준비했다. 로그인 화면에서 선택하면 공개 체험 아이디/비밀번호가 채워지고 일반 비밀번호 검증을 통과한 뒤 **로그인마다 독립 D1 사본**을 만든다. 지정 비공개 심사 계정은 변경하거나 초기화하지 않았다.

부모님과 철원4시간, 연인과 고성 바다, 친구와 화진포, 비어 있는 다음 휴가 계획, 지난 고성 여행으로 구성한다. 날짜는 로그인일 기준으로 정한다. 엄마·아빠·서연·친구들은 가상 인물이며 실제로 응답하지 않는다. 세 그룹의 공동 여행과 개인 여행은 서로 다른 사본이다.

가이드는 선택 사항이고 상단에서 다시 열 수 있다. 5단계 버튼이 실제 기능 화면으로 연결되며 완료 체크는 사용자가 직접 한다. 테스트 수정은 다른 테스터에게 보이지 않는다. 체험 계정은 개인 소셜 연결·기기 자료 가져오기·실제 그룹 초대/참여를 서버에서도 막는다. 계정 생성14일 경과 및 세션 만료를 모두 만족하는 예시만 로그인 시 최대3개 정리한다. 로그아웃해도 기존 게스트 그룹/공유 권한은 보존한다.

## 공유 설계와 참고 서비스

[Spotify Wrapped](https://newsroom.spotify.com/2025-12-03/2025-wrapped-user-experience/)의 개인 기록을 한 장으로 요약하는 방식, [Spotify의 공유 설계](https://newsroom.spotify.com/2022-09-01/scrolling-through-social-sharing-at-spotify-with-priscilla-chan-and-agnes-steinwall-berman/), [Strava 활동 공유](https://support.strava.com/en-us/articles/15401840-sharing-your-strava-activities)를 참고했다. 우리 서비스는 **계획 이미지→공개 장소 제안→실제 일정 저장→반영 전후 이미지**로 연결한다. 단순 댓글 수 대신 실제 계획에 반영된 상태를 보여준다. 이용자 증가나 바이럴 성과를 측정했다고 주장하지 않는다.

- 1080×1920 스토리 /1080×1350 피드 PNG, 숲·바다 색상, 로컬 Pretendard 글꼴.
- 계획과 방문 기록, 현재 출타의 상대적 남은 시간, 한 수 공유와 반영 결과를 지원한다.
- 정확한 날짜·시각·개인 제목·만남 장소·좌표·직접 입력 장소는 제외. 남은 시간은 기본 비공개이며 사용자가 선택한 경우 카드 생성 시점의 ‘약 N시간’만 표시한다.
- 공개 한 수는 링크와 QR로 연결한다. [Web Share](https://www.w3.org/TR/web-share/) 지원 기기는 사용자의 공유창, 그 밖은 PNG 다운로드. 인스타그램 스토리의 링크 스티커는 사용자가 붙이며 자동 게시/실시간 시계/게시 완료 감지를 제공한다고 설명하지 않는다.
- 공개안·반영 카드는 장소와 QR 위주로 구성해 비로그인 재공유도 가능하다. 계획·기록 카드는 TourAPI 사진을 사용할 수 있다.

## 사진과 데이터

[한국관광공사 국문 API 공식 설명](https://www.data.go.kr/data/15101578/openapi.do)을9/17 확인: 웹·홍보물·잡지 등 활용을 안내하며 공공누리1·3유형 이미지가 제공된다. PNG에서 **원본 비율·원본 전체·워터마크를 유지**하고 ‘사진 제공: ⓒ한국관광공사’를 표기한다. 외부 CC사진은 내보내기에 자동 혼합하지 않는다. 앱의 일반 관광사진 표시 기능은 유지한다.

사진 서버의 canvas CORS 제약 때문에 인증된 `/api/social-photo`가 고정 KTO호스트·검증한 /cms 경로의 바이트를 no-store로 중계한다. 다른 URL·SVG·리디렉션은 거부,12초/8MB 제한. JPG/JPEG/PNG/BMP 지원. 서버DB·파일 저장은 없으며 브라우저 페이지 메모리를 재사용한다. 이미지 오류 시 장소 목록으로 카드를 만들 수 있다. 조회되지 않은 관광지 참조는 내보내기를 막고 재시도 시 실패한 페이지 캐시를 비운다.
