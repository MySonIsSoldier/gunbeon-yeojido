# 2026-09-21 모든 사용자를 위한 여행 가이드

## 목적과 구현

기존 안내는 민준 체험·지정 심사 계정 중심이었다. 비회원과 일반 회원도 앱 상단의 **여행 가이드 다시 보기**로 같은 20초 안내와 기능별 5단계를 열 수 있게 했다. 홈·둘러보기·현재 출타·그룹·내 여행에서 동일하게 접근한다.

- 가이드는 코스 선택 → 일정 저장·편집 → 동행 그룹 → 한 수 받기 → 출타·기록 순서다. 각 단계의 버튼으로 해당 기능을 직접 연다.
- 저장된 여행이 없으면 추천 코스/빈 일정 만들기를 제안한다. 그룹이 없으면 생성 화면으로 연결한다. 진행 중 출타가 있으면 새 출타 대신 현재 여행으로 돌아간다. 빈 일정으로 공개 제안/출타를 시도하면 먼저 장소를 채우는 편집 화면을 연다.
- 처음 홈에 들어온 사람에게 시작 버튼과 갈 곳 고르기/우리 일정으로 저장/함께 갈 사람과 나누기의 세 단계를 제공한다. 내 여행·여행 기록·현재 출타의 빈 화면에 필요한 행동을 설명한다.
- 일반 사용자에게 매번 모달을 강제로 열지 않는다. 민준/지정 심사 계정의 첫 자동 안내, 명시적 tour=1 진입은 유지하며 초대·제안 링크를 가이드가 가리지 않게 한다. 건너뛰기·일시정지·직접 장면 이동·모션 감소 설정을 지원한다.
- 홈의 별도 16초 안내를 통합하고 실제 화면 안내 페이지 /guide도 갱신했다. 여행 정보·출처 버튼과 사용법 버튼의 역할을 분명히 했다.
- 안내를 보는 것만으로 여행/그룹/출타를 생성하거나 API를 추가 호출하지 않는다. 계정 인증·개인 저장·그룹 권한·실시간 출타·공개 정보 보호 계약과 TourAPI/Kakao 정상 기능은 유지한다.

## 검사

- TypeScript 통과, 단위 120/120 통과.
- 신규 test:onboarding: Chromium/Chrome 320·430·1440px 총 6개 통과. 비회원 수동 안내·새 일반 계정 안내·기능별 실제 이동·탭 이동/새로고침 후 재열기·키보드 닫기·모션 감소·가로 넘침 없음. 일반 계정은 로컬 D1에만 임의로 생성했다.
- test:tester-ui: Chromium 360·430·1440px 통과. 민준 로그인/자동 안내/일정/그룹/카드 다운로드/새로고침 유지.
- test:day: Chromium 360·430·1440·1920px 통과. 4장면/일시정지/건너뛰기/추가 관광API 호출 없음, 일정 조정·되돌리기·실제 방문 선택·공개 카드 개인정보 제외. 관광API quota 응답과 Kakao SDK 모의 검사이며 실연동 근거로 쓰지 않는다.
- test:guide: Chromium 360·1440px, 25개 안내 이미지/반응형·페이지 내 사진 재사용 통과.
- [실행 결과 및 대표 화면](qa/universal-guide/). 실제 휴대폰·Edge·보조기기 직접 검사는 이번 범위 밖이다.
- 최초 신규 회원 검사에서 테스트 요청에 Origin이 빠져 CSRF 방어로 거부됐다. 테스트에 정상 Origin을 추가해 통과했으며 서버 인증 보호는 변경하지 않았다.
