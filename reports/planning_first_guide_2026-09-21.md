# 9/21 처음 사용자를 위한 일정 준비 중심 안내

## 변경

- 민준·openapi 테스트 계정의 첫 안내와 모든 사용자의 상단 ‘여행 가이드 다시 보기’가 기능별 안내를 먼저 연다. 단계/확인 표시는 기존 기기에 기억한다. 여행·그룹이 없는 사용자는 첫 일정/첫 그룹을 만드는 안내를 받는다.
- 첫 행동은 ‘일정 열어보기’. 작은 화면에서도 설명 직후에 실행 버튼을 배치했다. 20초 애니메이션은 선택형이며 재생·일시정지·장면 이동·동작 줄이기를 유지한다.
- 일정 읽기 화면에서는 ‘일정 수정하기’가 주 행동이다. ‘출타 시작’은 보조 버튼이며 ‘출타는 실제로 떠나는 날’이라는 문구를 함께 표시한다. 현재 출타가 있는 경우 이어보기와 그룹 일정 가져오기는 유지했다.
- 가이드의 마지막 단계는 ‘여행 당일 화면 살펴보기’로 연결한다. 출타 후보 확인창을 자동으로 띄우지 않는다. 이용자가 여행을 고르고 복귀 기준을 확인해야 출타가 시작된다. 내 여행의 ‘여행 완료’도 보조 버튼으로 정리했다.
- 공통 Button의 스타일 식별자가 AlertDialog 합성 과정에서 바뀌어 취소 버튼이 작아졌던 문제를 고쳤다. 취소·실행 모두 높이 44px 이상, 데스크톱은 같은 세로 위치, 모바일은 같은 너비로 표시한다.
- 모든 확인창의 높이와 화면 바깥 여백을 제한했다. 긴 여행 완료 창은 내부 스크롤을 제공하고 제목에 초기 포커스를 둬 첫 화면 설명이 건너뛰어지지 않게 했다. 완료 버튼 주변 여백도 맞췄다.
- 공개 /guide의 설명과 실제 캡처, README, 기존 안내 회귀 검사 및 CI를 갱신했다. 제출 PDF/PPTX v3.3의 양식과 파일은 변경하지 않았다.

## 검증과 범위

- TypeScript 및 121개 단위 검사 통과. 개발/운영 Sites 빌드 성공.
- Chrome·Chromium 320/430/1440px × 민준/openapi 총 12개 체험 흐름: 기능별 자동 안내/재열기, 읽기 화면, 주/보조 버튼 구분, 안내를 통한 출타 미시작, 확인 취소, 두 확인창 버튼 정렬, 완료 창 제목 포커스, 선택형 애니메이션, 새로고침 후 안내 반복 방지 통과. [결과](qa/planning-first-guide/local/results.json).
- 비회원/신규 일반 계정 320/430/1440px 가이드, 빈 여행/첫 그룹 연결 통과. [결과](qa/planning-first-guide/guest/results.json).
- 일정 보기·편집·저장 회귀: 모바일 360/430px 및 데스크톱 1440px 통과. 최초 데스크톱 검사에서는 종료 애니메이션 도중 DOM 개수를 측정해 실패했으며, 화면 닫힘을 기다리는 조건으로 수정 후 재검증했다. [데스크톱 재검증](qa/planning-first-guide/itinerary-desktop/results.json).
- 출타·계획 Chrome 4크기 통과. 이어서 실행하려던 Edge는 이 PC에 없어 실행되지 않았다. 출타 관련 기능 계약을 바꾸지 않았다.
- 여유 조정/완료/기록 카드/선택형 애니메이션 4크기, 실제 독립 테스트 사본 편집/공개 제안 반영/출타 공유 시나리오 통과. [시나리오](qa/planning-first-guide/scenarios/result.json).
- /guide 360/1440px에서 모든 이미지 로딩·레이아웃 통과.
- 개발 사이트 비회원 가이드·추천 코스 연결·다른 탭에서 재열기 320/430/1440px 확인. [개발 결과](qa/planning-first-guide/development/results.json).

브라우저 화면 크기 재현이며 실제 휴대폰/Edge 검증은 아니다. 이번 작업의 테스트는 UI와 상태 전환을 확인한다. 일부 기존 회귀 검사는 지도 SDK/쿼터 응답을 대체하므로 TourAPI·Kakao 실연동 성공 근거로 사용하지 않는다. 자동 테스트는 독립 체험 사본만 사용하며 원본 심사 계정/일반 사용자 데이터를 초기화하지 않았다. 안내 확인이나 취소로 실제 출타가 저장되지 않는 것을 검사했다.

- 공식 gunbeon.gangwon.kr에서도 Chromium 320/430/1440px × 민준/openapi 6개 실제 체험 흐름을 통과했다. 버튼 높이 44px, 완료 창 최초 scrollTop 0, 출타 미시작 및 새로고침/재열기를 확인했다. [운영 결과](qa/planning-first-guide/production/results.json).
