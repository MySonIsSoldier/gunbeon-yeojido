# 기능설명서 v3.3 보완 검토 · 2026-09-21

기존 **v3.2, 18쪽**을 현재 운영 v23과 대조했다. 다섯 핵심 기능의 설명은 유지할 수 있지만, 최근 콘텐츠 확장과 체험 진입 방식이 빠져 있어 **5·6·7·9·16쪽**만 보완했다. 사용자 요청대로 공식 양식, 슬라이드 수·순서, 글꼴·색·배치, 표와 이미지의 프레임 크기는 유지한다. v3.2와 기존 1차 제출 키트는 당시 자료로 보존한다.

## 변경 내용과 판단 근거

| 쪽 | 검토 결과 | 반영 내용 |
|---|---|---|
| 5 지역특화 | 강원 콘텐츠의 구체적 제공 범위가 빠져 있음 | 접경 5군과 춘천·속초의 추천 코스 **36개** 명시 |
| 6 로그인·체험 | 민준만 소개하며 새 openapi 체험과 공통 가이드를 설명하지 못함 | 두 테스트 계정, 로그인별 독립 예시, 동일 로그인 중 수정 유지·재로그인 초기화, 20초 안내·5단계 가이드·상단 재열기. 운영 화면 2장 교체 |
| 7 장소 탐색 | 편집 화면의 검색만 소개해 둘러보기에서 여행을 시작하는 흐름이 누락됨 | 날짜 없이 코스·장소 탐색 → 내 일정으로 가져오기 → 일정에서 날짜·시간 설정. 7개 유형·추가 조회·한 장소부터 작성·직접 입력 설명. 실제 장소 찾기 화면 교체 |
| 9 동행 그룹 | 테스트 계정으로 실제 지인을 초대하려다 제한에 걸릴 수 있음 | 실제 지인 초대는 개인 계정에서 이용한다고 흐름에 명시 |
| 16 관광공사 API | 국문 관광정보의 확대된 조회 범위가 빠짐 | 7개 유형 검색과 목록 추가 조회 반영. 실사용 서비스는 **국문·무장애 2종** 유지 |

Google·네이버 로그인/계정 연결, 일정 보기·편집 분리, 개인 복귀 여유 비교, 기록 수정·계획 복원, 공개 제안의 실제 일정 반영, SNS 이미지/QR 기능은 이미 들어 있다. 같은 기능을 새 주기능처럼 중복 소개하지 않았다. 미래 기능이나 이용 성과를 현재 실적으로 추가하지 않았다.

## 사실 확인

- 36개 코스: 접경 5군 각 6개 + 관문도시 각 3개. 코스 완성에 필요한 관광정보가 조회되어야 화면에 표시된다. [콘텐츠 확장과 실제 API](../../../reports/content_guided_entry_2026-09-21.md).
- 7개 유형: 관광지·문화시설·축제/행사·레포츠·숙박·쇼핑·음식점. **하나의 국문 관광정보 서비스 안의 분류**다. 집중률·중심·연관 API는 실사용 항목에 추가하지 않았다. 변동하는 조회 건수를 고정한 확보 실적으로 제시하지 않았다.
- 두 테스트 계정은 현재 세션의 수정 상태를 D1에 임시 보존한다. ‘전혀 저장하지 않는다’고 쓰지 않는다. 새 로그인·다른 기기는 별도 초기 예시를 받고 기존 기기의 세션을 초기화하지 않는다. 실제 초대·참여, 개인 OAuth 연결, 기기자료 가져오기는 제한된다. [격리 구현·운영 검증](../../../reports/isolated_test_accounts_2026-09-21.md).
- 일반 회원·비회원도 상단 가이드를 열 수 있다. 계정과 준비된 여행의 상태에 따라 안내 버튼이 연결되며 20초 안내는 건너뛰기·일시정지·모션 감소를 지원한다. [공통 가이드](../../../reports/universal_guide_2026-09-21.md).
- 신규 사진을 외부에서 수집하지 않았다. 새 캡처의 관광지 사진은 ⓒ한국관광공사이며 사진 원본·워터마크를 수정하지 않았다. [기존 사진 출처 목록](image-sources.md), 새 화면은 `reports/qa/description-v3-3/screens/`에 보존한다.

## 양식 보존과 검수

Artifact Tool로 기존 문서의 해당 텍스트·이미지를 편집한 후 원본 OOXML에 승인된 내용 변경만 이식했다. 원본의 master/layout/theme/페이지 순서와 모든 도형의 좌표·크기·글꼴·표 구조를 대조한다. 편집 가능한 텍스트·표·화살표를 이미지로 바꾸지 않는다.

최종 PPTX 재열기·구조·레이아웃 검사, PDF 18쪽 변환·Pretendard 임베딩·10MB 제한, 바뀐 문장의 원래 글자 크기/상자 폭, 원본과 페이지별 픽셀 비교를 검사한다. 변경 페이지는 전체 크기로 확인하고 전체 18쪽의 흐름을 다시 살핀다. Microsoft PowerPoint 앱 직접 실행이나 물리 휴대폰 검사를 새로 했다는 의미는 아니다. [최종 검수 기록](../../../reports/qa/description-v3-3/review.json).

새 운영 캡처는 공개 openapi 로그인으로 만든 독립 체험에서 촬영했다. API 응답을 모의로 바꾸거나 기존 사용자의 여행·그룹을 편집하지 않았다. 초기 촬영에서 사진 로딩 대기가 빠져 자리표시자가 보였으므로 실제 이미지 로드 완료를 기다려 최종 촬영했다.
